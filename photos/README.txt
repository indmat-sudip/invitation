Put your photos in this folder, then they appear automatically:

  couple.jpg   main photo on the first page (portrait, about 3:4)
  1.jpg 2.jpg 3.jpg 4.jpg   gallery photos ("Our Moments")

Tips
- Keep each file under ~500 KB (resize to about 1200 px on the long side) so the page loads fast on phones.
- File names on GitHub Pages are case-sensitive: use lowercase .jpg.
- Want different names or more photos? Edit the "photos" part of config.js.
- Optional: photos/preview.jpg is a good picture for the WhatsApp link preview (see README).
